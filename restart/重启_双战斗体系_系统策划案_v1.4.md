## 1. 设计原理

> 「这是一款 JRPG，主角希恩随身携带一块怀表，能在「即时战斗」与「回合制指令战」之间切换。怀表既是剧情道具，也是系统开关。每按一次，希恩都会失去一段记忆——这就是真结局的代价。」

### 1.1 系统定位

《重启》是一款 JRPG，不是 ARPG。所有战斗都跑在双战斗体系之上。传统 JRPG 的两个痛点：① 野外刷级；② 回合制无聊。我们的解法：

| 维度 | 解决方案 |
|---|---|
| 野外 | 即时战斗（连招 + S/A/B/C/D 评级）—— 流畅，永不拖沓 |
| Boss | 强制回合制（普攻 / 战技 / 终结技 / CP / 能量 / 通用被动）—— 策略、可计算、可学习 |
| 切换 | 希恩按怀表；玩家可按 R 强制回合制（希恩必须在队伍中） |
| 等级 | 绑定剧情里程碑（探索 / 任务 / 遗迹 / Boss）—— 不刷级 |
| 操作设计（v1.3） | L1 通用键位 + L3 每个角色独特战斗风格 |

### 1.2 设计目的

| 传统 JRPG 痛点 | 本作解法 |
|---|---|
| 野外重复 | 即时连招 + 里程碑等级，把玩家注意力引导到探索上 |
| Boss 策略 | 回合制 + 行动条 + CP + 能量 —— 动手前先动脑 |
| 成长拖沓 | 里程碑等级 —— 不刷怪 |
| 灵脉跨模式 | 灵脉只在回合制生效（约束即设计） |
| 操作雷同（v1.3） | 每个角色独特战斗风格；切换角色就是切换玩法 |

### 1.3 用户体验

| 时间节点 | 玩家感受 |
|---|---|
| 30 秒 | 我在一片古老大陆——6 神故事开场 |
| 序章中段 | 希恩出现，按下怀表，世界变慢——这就是回合制 |
| 每一章 | 不刷级，剧情节点 = 升级 |
| 中期（v1.3） | 每个角色操控手感不同，玩家找到自己最爱的战斗风格 |
| 第一个 Boss | 这游戏有深度。打输了能告诉朋友：「我输是因为忘了在第 2 阶段打断他的冲锋」——这就是目标体验 |

## 2. 系统总览

为什么这份策划案看起来更像文案？因为 JRPG 的系统设计与叙事设计天然不可分。JRPG 的玩家留存靠的是「我信这个世界」——而不是「这个技能很强」。所以这份文档里你会看到大量世界观、台词、设定——这些不是装饰，是绑定系统的绳索。

JRPG 大厂（Falcom / Atlus / SE）都是这么做的：写在前头，让你 / 队友 / 面试官知道这文案风是设计选择，不是跑题。

> **写每条规则时，我都会回答 4 层「为什么」：**
> - L1 已有哪款游戏 / 设计做过类似的事？
> - L2 这条规则具体解决玩家的什么问题？
> - L3 这条规则为什么真能留存或打动玩家？
> - L4 套用了什么设计理论 / 概念？
>
> 后面规则里我只挑关键的几条展开 4 层，其它地方留 L1 + L2 即可。

### 2.1 系统一览

| 模块 | 作用 |
| --- | --- |
| 双战斗（野外 + Boss） | 野外即时；Boss 回合制 |
| 等级系统 | 等级绑定剧情节点——不刷级 |
| 装备系统 | 任务 / 遗迹掉落，两种战斗模式共用 |
| 灵脉 + 灵核 + 符文 | 技能树 + 装备插槽（仅回合制） |
| 怀表（失落者的时间） | 道具 = 开关 = 结局触发器 |
| 操作设计（v1.3） | L1 通用键 + L3 每角色独立 |

### 2.2 世界观设定

JRPG 必须答：「这是哪？为什么是这样？」我们的世界答：「为什么周日怪物很弱？为什么希恩能切换战斗？为什么魔法存在？」

#### 创世 6 神

| 日 | 神 | 神话 | 怪物强度 |
|---|---|---|---|
| 周一 | 光明神 | 带来光明，驱散黑暗 | 周一：光系怪物强 |
| 周二 | 生命神 | 带来生命，滋养大地 | 周二：生命系怪物强 |
| 周三 | 源质女神 | 带来变化 | 周三：变化系怪物强 |
| 周四 | 战争与艺术神 | 带来勇气与艺术 | 周四：技艺系怪物强 |
| 周五 | 机械与智慧女神 | 带来对智慧的追求 | 周五：机械系怪物强 |
| 周六 | 死亡君主 | 宣告生命之死 | 周六：死亡系怪物强 |
| 周日（安息日） | 众神安息 | — | 周日：所有怪物魔法被压制，比平时更弱 |

#### 主角登场

序章由女性卫队长爱丽丝开场。周日怪物本该很弱，但今天它们发疯了。爱丽丝和卫兵用即时战斗迎敌（这是野外战斗的预演）。

战况不利时，真正的主角希恩出现，手持怀表，按下开关——

> 「在一定范围内，所有怪物与同伴开始以某种特殊规则有序行动。卫兵成功击退了怪物。」

#### 两大核心设定

**失落者的时间（怀表）**：希恩的怀表在范围内对有机生命施加「秩序」。按怀表 = 切换战斗模式。每按一次，希恩失去一段记忆（联动真结局，见 3.7）。

**祝福者（魔法使用者）**：拥有魔法的人。多数平民不会用魔法。魔法工学（类似工业革命）诞生，让普通人也能用魔法。大部分可操作角色都是祝福者。

#### 6 派系镜像 6 神

6 个灵核派系 = 6 神（周一到周六）。世界与系统绑定。玩家永远不会问「为什么是 6」——因为创世就有 6 神。

### 2.3 系统一览（嵌套式）

- 战斗系统
  - 即时（野外）：L1 通用键 + L3 每个角色独特（空轨 + 鬼泣 混合）
  - 回合制（Boss / R 键）：普攻 / 战技 / 终结技 / CP / 能量 / 通用被动
- 养成系统
  - 等级：绑定世界里程碑，不刷级
  - 装备：任务 / 遗迹，两模式共享
  - 灵脉：3 槽位 × 核心灵核 + 2 自由灵核，5 条符文分支（**仅回合制生效**）
- 6 派系：祝福 / 坚韧 / 源质 / 主宰 / 精密 / 亡灵

### 3.1 M1 双战斗切换

#### 是什么

希恩按下怀表：战斗从即时连招切换到回合制指令。再按一次（或离开战斗区域）切回即时。叙事上是「施加秩序」，系统上是「模式切换」。

#### 切换规则

| 方式 | 触发条件 | 结果 |
|---|---|---|
| 野外默认 | 无输入 | 即时连招模式（野外） |
| R 键手动 | 希恩在场 + 按 R | 强制回合制（随时） |
| 精英 / Boss 遭遇 | 剧情标签敌人 | 强制回合制 + 入场演出 |
| Boss 阶段切换 | Boss 脚本触发 | 允许短暂即时追击演出 |
| 切回即时 | 关闭指令菜单 | 恢复行动，HP / 持续 Buff 保留 |

#### 为什么这样设计

野外用即时 → 不刷级的流畅体验。Boss 用回合制 → Boss 难，需要策略。

#### R 键硬约束：希恩必须在场

- **核心约束**：玩家可以随时按 R 切回合制，但希恩必须在队伍中。
- **剧情分支**：中期队伍会分成两条路线——希恩缺席的那条路线，R 键失效。
- **后期（真结局前）**：怀表和 R 键同时禁用——希恩献祭机制。

#### 待补完

- 入回合制演出长度（建议 < 3 秒）
- 剧情分支章节 / 队伍组成

### 3.2 M2 即时战斗（野外）—— v1.3 操作框架

#### 是什么

野外战斗时，玩家用键鼠 / 手柄直接操控。操作设计遵循 3 层框架，融合空轨（低门槛）与鬼泣（高差异化）之长。

#### 3 层操作框架（v1.3 核心设计）

**设计哲学支柱（v1.3）**：
- L1 通用键（左攻击 / 右重击 / 空格闪避 / 闪避接轻击 / 闪避接重击）
- + L3 每个角色独特战斗风格
- = 低门槛（5 分钟上手任意角色）+ 高差异化（每个角色都需要精通）

| 层级 | 空轨系列 | 鬼泣 | 本作设计（v1.3） |
|---|---|---|---|
| L1 通用操作 | 有 —— 全角色共用基础键 | 无 —— 每角色独立键位 | 有 —— 借空轨通用层 |
| L2 派生操作 | 弱 —— 低连段 | 强 —— 丰富连段 | 有 —— 每角色独立派生 |
| L3 独特战斗风格 | 弱 —— 仅角色定位差异 | 强 —— 每角色机制差异 | 有 —— 每角色机制独立 |

**设计思路**：空轨低门槛（L1）+ 鬼泣差异化（L3）。既避免空轨同质化，又保持低上手难度。

#### L1 通用操作层（强制，所有角色共享）

| 键 | 动作 | 备注 |
|---|---|---|
| 左键 / X | 轻攻击（基础连段） | 连按 = 3-5 段连击 |
| 右键 / Y | 重攻击（慢，高伤） | 在正确帧取消 L1 连段 |
| 空格 / B | 闪避 / 冲刺 | 动画期间无敌帧 |
| Shift + 左 | 闪避接轻击 | 帧级取消，用于反击 |
| Shift + 右 | 闪避接重击 | 高风险高收益 |
| Q / E | 技能 1 / 技能 2 | 冷却制 |
| R | 强制回合制切换（希恩在场时） | 模块 M1 |

#### L3 每个角色独特战斗风格（v1.3 关键设计）

这是设计支柱：每个角色都有超越 L1+L2 的独特战斗机制。L3 差异化示例：

| 角色 | L3 机制 |
|---|---|
| 希恩 | 怀表操纵：战斗中开启短时间现实扭曲窗口。例：L1 连段中触发 0.5 秒慢时 = 可连出不可能角度 |
| 爱丽丝 | 双持卫队长：L2 闪避接攻击触发「格挡反击」窗口。冒险家玩法 |
| 蒂卡 | 移动工坊：战斗中部署可召唤构造物。低 DPS 但区域控制 |
| 卡列琳娜 | 魔攻远程 DPS：重击发射抛射物。低机动但清场能力强 |

- **待补完**：每角色 L1+L2 连段表 + L3 独特机制详细
- **待补完**：每角色 L3 独特机制动画

#### 玩法体验

| 阶段 | 说明 |
|---|---|
| 基础 | L1 通用键——5 分钟上手任何角色 |
| L2 派生 | 每角色独立连段与取消窗口 |
| L3 精通 | 每角色独特机制——100 小时完全掌握 |
| 评级 | 每场战斗 S / A / B / C / D 评级。影响掉落 |
| 可读风险 | 敌人攻击前摇 + 范围高亮——玩家看到再反应 |

#### 绝对不能发生

| 红线 | 后果 |
|---|---|
| 野外长菜单 | 赶走轻动作玩家 |
| 连段堆叠秒杀 Boss | 掏空回合制意义 |
| 野外吃灵脉构筑 | 灵脉只在回合制——野外仅基础属性 |
| L3 独特破坏 L1 通用 | L3 必须延展 L1，而非覆盖。每条 L3 都尊重「左 / 右 / 空格」 |

### 3.3 M3 回合制指令（Boss / 精英）—— v1.3 压力设计

#### 是什么

Boss / 精英战（或 R 键手动切换），战斗进入回合制。参考空轨行动条系统，但我们移除了：魔法、防御指令、Burst、Quartz Burst。

#### 指令菜单

| 指令 | 消耗 | 效果 |
|---|---|---|
| 普攻 | 无 | 基础物理攻击 |
| 战技 | CP（通用行动资源） | 角色独有招数 |
| 终结技 | CP + 能量 | 大招 |
| 道具 | 道具栏 | 治疗 / 净化 / Buff 等 |
| CP | — | 通用行动资源。野外通过攻击 / 完美闪避累积。Boss 战消耗 |
| 能量 | — | 高消耗资源（终结技）。Boss 战关键时刻使用 |
| 通用被动 | — | 角色天赋被动，常驻生效，无需选择 |

#### 真结局 Boss 压力设计（v1.3 新增）

**设计哲学支柱（v1.3）**：
后期（真结局前）Boss 拥有凶残的技能组（反极限闪避 / 时间停止 / 全屏追踪 / 持续掉血）。

压力与公平必须共存。压力制造剧情张力，公平保持玩家不弃坑。

**解决方案**：4 红线 + 阶段式机制分配。

#### 压力设计 4 红线

| 红线 | 风险 | 缓解措施 |
|---|---|---|
| 1. 可读性 | 所有危险信号叠在一起 = 屏幕混乱 | 每个机制都有 0.3-0.5 秒反应窗口；清晰颜色编码 |
| 2. 可规避 | 无反制 = 受挫 | 每个凶残机制都对应唯一一种 L1+L2 反制（闪避） |
| 3. 公平 | 死亡必须可读 | 死亡回放 + 事后「这个攻击可被 XX 反制」 |
| 4. 成就感 | 胜利必须感到来之不易 | 终结技演出 + 结算页高亮「关键时刻」 |

#### 阶段式机制分配（避免混乱）

参考《只狼》苇名一心（3 阶段，每阶段 1 新规则）/《黑神话》大圣（4 阶段，每阶段 1 新规则）。4 个凶残机制不是同时上场，而是分散到阶段里：

| 阶段 | 新机制 | 已有机制状态 |
|---|---|---|
| 阶段 1 | 反极限闪避（Boss 在玩家闪避时攻击） | 其他 3 个休眠 |
| 阶段 2 | 时间停止（Boss 冻结玩家 1 回合） | 反极限闪避 + 新机制 + 其他休眠 |
| 阶段 3 | 全屏追踪抛射物 | 反极限闪避 + 时间停止 + 新机制 + 持续掉血休眠 |
| 阶段 4（真结局） | 持续掉血机制（DoT + 层数） | 全部 4 个激活——这是高潮 |

玩家在孤立状态下先学会每个机制的反制，再遇到组合。这就是 v1.3 压力-公平的平衡点。

### 3.4 M4 里程碑等级

#### 是什么

传统 JRPG：升级 = 刷经验条。本作：升级 = 剧情里程碑触发。

#### 运行方式

| 节点 | 说明 |
|---|---|
| 里程碑节点 | 首次进入新区域 / 完成关键任务 / 解锁遗迹 / Boss 战后 |
| 等级上限 | 受世界探索程度限制 |
| R 键使用次数 | 希恩能按 R 的次数 = 绑定等级 / 探索 |

### 3.5 M5 装备系统（v1.4 重新设计）

#### 设计哲学

> **稀缺性 × 长期养成**：传说装备只从遗迹稀有掉落，升星系统强化传说装备的被动，让传说装备真正成为「值得追的终极目标」，而不是「量产的高端消耗品」。

#### 装备基础

- 4 个部位：武器 / 头盔 / 胸甲 / 鞋
- 最高锻造等级：5 级（找工匠升级）
- 品质分级：普通 / 稀有 / 史诗 / **传说（仅遗迹获得）**

#### 装备来源（v1.4 完整版）

| 来源 | 可获得品质 | 货币 / 条件 |
|---|---|---|
| ① 城镇装备商店（节点 5 解锁） | 普通 / 稀有 | 金币 |
| ② 遗迹探索（节点 5 解锁） | 史诗 / 传说（随机掉落） | 无（看脸） |
| ③ 蒂卡点石成金（蒂卡入队后） | 普通 / 稀有 → 史诗 | 装备 + 少量金币 |

**蒂卡点石成金机制**：
- 输入：普通或稀有品质装备 + 少量金币
- 输出：史诗品质装备
- 限制：每个装备只能点石一次
- 解锁节点：蒂卡入队后（蒂卡不在队伍 → 无法点石）

#### 升星系统（v1.4 重新定位）

> **核心约束**：升星系统**只作用于传说品质装备**。作用是强化传说装备的被动效果。升星不改变品质，不跨越品质。

| 维度 | 说明 |
|---|---|
| 作用对象 | **仅传说品质装备** |
| 作用效果 | 强化传说装备的被动 |
| 是否改变品质 | 否（传说升星后仍是传说） |
| 升星材料 | 专属升星道具（暂未设计） |

#### v1.3 → v1.4 关键变更

| 维度 | v1.3（旧） | v1.4（新） |
|---|---|---|
| 传说装备来源 | 史诗 + 升星 | **仅遗迹稀有掉落** |
| 升星系统作用 | 史诗 → 传说（跨越品质） | **强化传说装备的被动** |
| 史诗装备来源 | 任务 / 遗迹 | 任务 / 遗迹 / 蒂卡点石成金 |
| 装备稀缺性 | 中（升星可量产传说） | **高（传说严格稀缺）** |
| 前期过度风险 | 高（升星系统开放后传说量产） | **低（升星系统 ≠ 玩家能获得传说）** |

#### 角色差异化

| 队伍配置 | 史诗装备 | 传说装备 |
|---|---|---|
| 蒂卡在队伍 | 量产（点石成金） | 仅遗迹掉落 |
| 蒂卡不在队伍 | 仅遗迹掉落 | 仅遗迹掉落 |
| 关键洞察 | **蒂卡不能解决传说装备** | 传说独立于队伍配置 |

#### 设计意图

- **传说装备 = 真正的稀有奖励**：玩家不能靠升星量产传说，只能靠遗迹运气 → 稀缺性 → 珍惜感 → 二周目目标
- **升星系统 = 长期养成系统**：玩家 30 小时获得第一件传说装备，之后 100 小时都在升星 → 升星是终极养成曲线
- **蒂卡点石成金 = 解决「前期有没有史诗」问题**：没有蒂卡 → 史诗只能靠遗迹运气（前期卡关）；有蒂卡 → 史诗稳定量产（前期流畅）。但传说仍然是瓶颈——**这才是真正的角色差异化**
- **装备金字塔（4 层来源完整版）**：

  - 传说（升星强化被动）← 长期养成，最稀有
    - 来源：仅遗迹随机掉落
    - 升星作用：强化传说装备的被动
  - 史诗（遗迹 + 蒂卡点石）← 稀缺但可量产
    - 来源：遗迹 / 蒂卡点石成金（普通或稀有 + 金币）
    - 升星作用：不适用
  - 稀有 / 普通（商店）← 日常保底
    - 来源：城镇装备商店
    - 升星作用：不适用

### 3.6 M6 灵脉 + 灵核 + 符文（核心养成）

> **核心约束**：本模块所有效果**只在回合制模式**生效。野外即时战斗不享受灵脉加成，仅基础属性（攻击 / 防御）。

**设计哲学支柱（v1.2）**：
灵脉仅回合制 → 后期无回合制（真结局前）→ 玩家从机制层理解「希恩不可替代」

**承载性决策**：绑定养成 + 剧情高潮 + 结局机制。

**为什么灵脉仅回合制**：

- 体验类比：参考空轨——技能槽只在 AT 战中生效。我们推得更远，整套养成仅回合制
- 玩家痛点：动作玩家用养成构筑平推野外，绕过回合制；这套规则让动作 / 策略玩家各得其所
- 玩家心理：一旦灵脉进入即时战斗，就变成策略游戏，与动作手感冲突
- 体验设计：全通有 2 个结局，后期玩家无法切回回合制——这条约束让真结局章节（无回合制）的「希恩献祭」从机制层落地

#### 6 灵核派系技能方向

| 派系 | 神 | 一句话 | 技能 / 被动方向 |
|---|---|---|---|
| 祝福 | 周二 生命神 | 群体治疗 / Buff / 资源控制 | 群奶 / 护盾 / 团队增益 |
| 坚韧 | 周一 光明神 | HP + 双防 / 回复 / 护盾 | 受伤减免 / 治疗 / 受击反击 |
| 源质 | 周三 源质女神 | 资源控制 / 规则操纵 | EP 经济 / 特殊规则扭转 |
| 主宰 | 周六 死亡君主 | 行动条抢占 / 爆发伤害 | 眩晕 / 偷回合 / 终结技强化 |
| 精密 | 周五 机械智慧女神 | 固定伤害 / 连段增益 / 长线 | 暴击 / 命中 / 层数伤害 |
| 亡灵 | 周四 战争艺术神 | 召唤单位 / Debuff | 召唤骷髅 / Debuff / 回合延长 |

#### 为什么是这 6 个

| 角色定位 | 派系 |
|---|---|
| 防御续航 | 祝福 + 坚韧 |
| 资源控制 | 源质 + 主宰 |
| 输出节奏 | 精密 + 亡灵 |

### 3.7 M7 怀表（失落者的时间）（系统 + 叙事）

> **核心**：怀表是剧情道具 + 系统开关 + 真结局触发器。每次按怀表，希恩失去一段记忆（联动真结局）。

**设计哲学支柱**：
怀表是主角献祭机制。结合 M6（灵脉仅回合制）+ 后期「R 键不可用」，
怀表成为「希恩为了让玩家赢而献出什么」的象征。

记忆流失累积 → 真结局只给依赖希恩的玩家 → 「希恩为玩家献祭自己」的叙事被机制落实，而不只是剧本。

#### 运行方式

| 时机 | 动作 | 结果 |
|---|---|---|
| 野外 | 希恩按怀表 | 切换回合制。再按一次切回即时 |
| Boss 战 | 希恩按怀表 | 调整行动条节奏 |
| R 键 | 玩家按 R | 强制回合制（希恩在场） |
| 后期 | 剧情触发 | 怀表禁用；R 键禁用；玩家必须全程即时 |
| Boss 战后 | 自动结算 | 这次使用记录到记忆流失计数器 |

#### R 键硬约束

- 希恩必须在队伍中才能用 R
- 中期队伍分裂 → 希恩缺席路线 R 键失效
- 后期（真结局前） → R 键完全禁用（希恩献祭）
- **设计意图**：R 键 = 希恩的价值，不是免费切换

## 8. v1.4 新增内容总结

### v1.3 → v1.4 核心变更

1. **全文翻译为中文**（从英文 v1.3 翻译过来）
2. **装备系统（M5）完全重做**：
   - 引入 4 来源体系：商店 / 遗迹 / 蒂卡点石成金 / 升星
   - 明确品质 × 来源对应关系
   - 升星系统重新定位为「传说装备被动强化」而非「史诗 → 传说跨越」
   - 传说装备严格限制为「仅遗迹获得」
3. **加入装备金字塔设计哲学**：
   - 普通 / 稀有 → 商店保底
   - 史诗 → 遗迹 + 蒂卡点石成金（稀缺但可量产）
   - 传说 → 仅遗迹（最稀有）+ 升星强化被动（长期养成）
4. **角色差异化明确**：
   - 蒂卡解决「前期有没有史诗」问题
   - 但蒂卡不能解决「有没有传说」
   - 传说装备独立于队伍配置

### 设计哲学进化

> 从「装备分级量产」（升星可量产传说）
> 到「装备稀缺养成」（升星 = 长期养成终极曲线）

这是从「装备消费体验」到「装备养成体验」的设计哲学转变——更贴近《最终幻想》《轨迹》系列的核心 JRPG 装备哲学。
